# chair

A modern, high-end luxury furniture digital experience built with React, TypeScript, Vite, and Three.js.

## Features
- **Auto-scrolling Lookbook Carousel**: High-fidelity hero showroom featuring curated furniture collections with smooth transitions and progress indicators.
- **Interactive 3D Furniture Studio**: WebGL/Three.js interactive product viewer with 360° orbital rotation, wireframe toggle, dynamic fabric color swatches, and hotspot callouts.
- **Product Catalog & Mega Menu**: Filtering by room (Living Room, Bedroom, Dining Room, Office, Storage), instant search with live results, and category breakdown.
- **Interactive Quick View & Cart Drawer**: Slide-out cart with coupon validation, free shipping threshold progress, and multi-step checkout modal.
- **Mobile Floating Dock**: Sleek glassmorphic mobile navigation bar.

## Tech Stack
- React 19 + TypeScript
- Vite
- Three.js
- Lucide React
- Canvas Confetti

## Getting Started
```bash
npm install
npm run dev
```
